# Docker 種別 (Version 4 以降)

!!! info "整備中"
    このページは **BayServer Version 4 以降** の Docker リファレンスです。Version 4 のリリースに合わせて 1 から作り直す予定です。それまでの間、暫定的に [Version 3 以前のリファレンス](docker-types-v3.md) を参照してください。

## 目次 (= 整備予定)

V4 リファレンスでは以下の構成を予定:

- 大分類 (= Docker の種類の俯瞰)
- パラメータの型
- 各 Docker の詳細
    - Harbor Docker
    - Port Docker (HTTP / AJP / FCGI / H3)
    - Secure Docker
    - City Docker
    - Town Docker
    - Club Docker (= File / CGI / PHP / Servlet / Warp / WordPress / その他)
    - Permission Docker
    - Log Docker
    - Reroute Docker
    - Trouble Docker
    - Barge Docker
    - (= Version 4 で追加 / 変更される Docker)

各 Docker について:

- 役割と設置場所 (= 親 Docker の制限)
- パラメータ一覧 (型 / デフォルト値 / 意味)
- 設定例
- Version 3 以前との差分 (= 該当する場合)
