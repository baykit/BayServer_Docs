汎用的な内容 (= プラン文法、docker 種別、運用方法) は [リファレンス](../reference/) と [ガイド](../guide/) を参照。本セクションでは「Java 版だけここが違う」「PHP 版だけここが違う」といった**実装固有の差分**のみを扱います。
