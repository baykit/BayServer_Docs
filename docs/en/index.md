# BayServer Documentation

**BayServer** is a high-performance web / proxy server with multiple-language implementations (Java, PHP, Ruby, Python, C) that share the same `.plan` (= configuration file) format. This site collects the concepts, usage, operations, performance tuning, and developer information.
